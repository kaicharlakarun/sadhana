# Sadhana RR Enterprises

Official website and digital booking portal for **Sadhana RR Enterprises** — India's premier heavy equipment rental partner and provider of crane & boom lift rental services in Visakhapatnam (Vizag) and nationwide.

## 🏗️ Fleet & Services
- **Mobile & All-Terrain Cranes:** 50T – 300T telescopic heavy cranes
- **Hydraulic Crawler Cranes:** 50T – 500T lattice boom cranes
- **Articulated & Telescopic Boom Lifts:** 45ft – 150ft self-propelled manlifts
- **Truck-Mounted Sky Lifts:** 18m – 70m high-elevation access platforms
- **Pick & Carry Mobile Cranes:** 12T – 30T Hydra & Farana cranes
- **Scissor Lifts:** Electric & diesel rough-terrain models
- **Heavy Haulage Trailers:** Low bed, semi-low bed & multi-axle modular trailers
- **Industrial Forklifts:** 3T – 16T heavy-duty diesel and electric units

## 🚀 Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **SEO:** Structured Schema Markup, XML Sitemaps, Robots configuration

## 🛠️ Getting Started

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Start production server:
```bash
npm run start
```
